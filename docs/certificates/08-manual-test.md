# Ручной чеклист (dev / staging)

1. В `app.preview.student-ids` добавить тестовую зачётку.
2. Админу выдать `CERTIFICATE_REVIEW_*` нужного филиала.
3. Студент (preview): Сервисы → Справки → загрузить PDF и JPG → статус «На проверке».
4. Родитель той же зачётки: то же.
5. Вне preview → ComingSoon / API 403.
6. Админ чужого филиала → нет заявок / 403.
7. Админ своего филиала: открыть → скачать → одобрить с датами → у заявителя период в списке.
8. Другая заявка → отклонить с причиной → причина видна заявителю.
9. В настройках раздела указать notify email → новая заявка шлёт письмо; очистить email → писем нет.
10. Одобрить период на сегодня до 21:00 → в автоотчёте кампуса студент не в мониторинге (warning «Исключены по одобренным справкам»).
11. Одобрить после сборки → готовый отчёт не меняется.
