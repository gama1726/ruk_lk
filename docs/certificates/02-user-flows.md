# Сценарии: справки и оправданные отсутствия

Связано с [`01-requirements.md`](01-requirements.md).

## Студент / родитель

### F1. Открыть раздел (dev)

1. Вход студента или родителя.
2. При `previewEnabled` — пункт «Справки».
3. Иначе раздел скрыт.

### F2. Подать заявку

1. «Загрузить справку».
2. Тип: больничный / военкомат / прочее.
3. Файлы PDF/JPG/PNG/HEIC (≤ 50 МБ), комментарий по желанию.
4. Период **не** спрашиваем.
5. Кампус подставляется из профиля студента автоматически.
6. «Отправить» → `PENDING` → очередь раздела филиала + уведомление админу.

### F3. Статусы

1. Список заявок и карточка (причина отклонения видна).
2. Отозвать `PENDING` → `CANCELLED`.
3. Можно создать новую заявку, даже если другая PENDING/APPROVED.

### F4. Уведомление заявителю

- Одобрена: период с–по.
- Отклонена: текст причины.

## Админ

### F5. Три раздела

Отдельные пункты: справки Голова / Казань / Краснодар. В каждом — только заявки этого кампуса.

### F6. Решение

1. Скачать файл → проверить подлинность **вне ЛК**.
2. Одобрить + даты с/по (полные дни) **или** отклонить + обязательная причина.
3. Уведомление заявителю.

### F7. Отчёт

1. Сборка в 21:00 (или ручная): исключить APPROVED с периодом на день отчёта.
2. Поздний approve сегодня — сегодняшний готовый отчёт не меняем; дальше дни периода учитываются.

## Краевые случаи

| Ситуация | Ожидание |
|----------|----------|
| Родитель без preview по зачётке ребёнка | Раздел скрыт / API отказ |
| Админ чужого кампуса | 403 |
| HEIC | Принять и нормализовать как у pass-photo (или отказ с понятным текстом, если конвертация невозможна) |
| PDF 51 МБ | 413 / сообщение о лимите |
| Approve: to &lt; from | 400 |
| Две APPROVED на пересекающиеся дни | Обе валидны; exclusion по OR |

## Копирайт (черновик)

- Меню: «Справки»
- Кнопка: «Загрузить справку»
- Типы: «Больничный» / «Освобождение от военкомата» / «Прочее»
- Админ: «Одобрить» / «Отклонить» / «Период отсутствия»
- Подсказка админу: «Перед одобрением убедитесь в подлинности документа по порядку филиала.»
