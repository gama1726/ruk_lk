# Инструкция сотруднику: очередь справок

## Доступ

Учётка админки ЛК с галочкой справок **нужного филиала** (Голова / Казань / Краснодар).  
Три отдельных раздела — в каждом только заявки своего филиала.  
Галочка «Отчёт отсутствующих» **не** открывает справки сама по себе.

## Email о новых заявках

В разделе справок филиала можно указать **почту для уведомлений**.  
Если поле заполнено — при новой заявке уйдёт письмо. Если пусто — только очередь в панели (по желанию филиала).

## Работа с заявкой

1. Открыть раздел справок своего филиала → «На проверке».
2. Скачать файл (PDF или фото).
3. Проверить подлинность **вне ЛК** (ЕМИАС и др. — ваши инструменты; в кабинете кнопок проверки нет).
4. **Одобрить** — указать период отсутствия **полными днями** (с / по). Студент/родитель получит уведомление.
5. **Отклонить** — **обязательно** написать причину (её увидит заявитель) + уведомление.

Период на форме подачи студент не указывает — задаёте только вы при одобрении.

## Отчёт отсутствующих

- Сборка около **21:00 МСК**.
- Если к этому моменту справка уже одобрена и день входит в период — студента не должно быть в мониторинге.
- Одобрили **после** сборки за сегодня — сегодняшний готовый отчёт не меняется; исключение сработает на **следующие** дни периода.

## Типовые случаи

| Ситуация | Действие |
|----------|----------|
| Нечитаемый / не тот файл | Отклонить с причиной |
| Сомнение в подлинности | Не одобрять, пока не проверите вне ЛК |
| Нужен доступ к другому филиалу | Супер-админ выдаёт галочку секции |
| Студент всё ещё в отчёте | Проверить время одобрения и даты периода; эскалация в разработку |
